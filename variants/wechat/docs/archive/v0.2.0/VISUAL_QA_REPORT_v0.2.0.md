## 针对旧版截图 bug 的结构性处理

旧版把首次引导作为主页上方的遮罩层，主页 Canvas 同时存在；这让 UI 正确性依赖组件层级和同层渲染行为。

v0.2.0 已改为：

```text
showOnboarding = true  → 只渲染首次引导，不创建 Canvas
showOnboarding = false → 只渲染主页，才创建 Canvas
```

另外，Canvas 容器内部只保留 Canvas 本身，不再覆盖普通 `view` 的即时反馈浮层。反馈卡改放在记账区，降低渲染层级风险。

该结构由 `tests/static_check.py` 强制检查，后续修改如果重新把普通 View 压到 Canvas 上，会直接让自动检查失败。
