# v0.2.0 变更记录

## 为什么不是 v0.1.x 补丁

v0.1.x 暴露的是基础迁移质量问题，不只是一个 CSS 层级问题：页面文件漏包、首启结构依赖叠层、Canvas 生命周期缺少系统性约束、计算口径也曾偏离原始设计。因此 v0.2.0 按「重新验收的完整版本」处理。

## 结构改动

- 首次引导与主页互斥渲染；
- Canvas 首次引导期间完全不存在；
- Canvas 区域移除普通 View 叠层反馈；
- 首页 Canvas 生命周期统一到 `onReady/onShow/onResize/onUnload`；
- 设备像素比改用 `wx.getWindowInfo()`；
- 所有页面固定四件套并加自动存在性检查。

## 模型修正

v0.1 迁移曾将记账跨度计算成「首笔交易 → 最后一笔交易」。这与原项目《设计方案.md》不一致。

v0.2.0 恢复为：

`记账跨度 = 今天 − 首笔有效交易日期 + 1`

并增加：
- 无效/未来交易不参与统计；
- 自由天数不允许负数；
- 2 月 29 日生日的目标日期处理；
- 高级覆盖口径规范化。

## 首次体验

- 第 1 屏只讲核心理念；
- 第 2 屏讲正确心态；
- 第 3 屏说明每笔反馈；
- 第 4 屏才输入生日/目标年龄；
- 默认第一笔交易类型改成支出；
- 高级参数只在设置页出现。

## 测试体系

新增并通过：
- 数学模型测试；
- Storage 测试；
- 首页交互流程模拟测试；
- 静态项目结构/WXML/JS 检查；
- 多尺寸视觉等价截图；
- 320×568 小屏压力检查。
