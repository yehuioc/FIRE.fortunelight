# v0.5.1 完整对抗 / 炒面测试收口

本轮不只测试 NaN、空字符串等非法输入，而是攻击“用户行为完全合理，但开发者可能没想到”的状态顺序。

## 已覆盖的主要场景

- 高级 → 上手 → 保存 → 跨会话再回高级；
- 首启高级 → 临时查看上手 → 再回高级；
- 首屏已有备份直接恢复；页面销毁后迟到回调；
- 配置已改但未保存时导出/导入；
- 同一时刻连续导出备份；
- 旧版本设置升级后立即导出/恢复；
- 脏内部 metadata、重复 ID、重复系统基准、损坏交易数组；
- Storage 读失败、写失败、删除失败、迁移失败、清空失败；
- 设备时钟回拨 / 跨时区；
- 修正出生日期与既有账本冲突；
- 目标年龄在多年后自然到期；
- 第三位小数、精确分边界、大额长期累计；
- 50,000 笔长期账本计算 + 备份 + 清空 + 恢复闭环；
- 仪式创建前提前点“跳过”；页面隐藏期间仪式收尾；
- FREE 后立即产生真实消费，边界允许重新熄灭；
- 首启最后一步快速连点；
- 设置保存后立即离页，防止延迟 navigateBack 多退一层；
- 交易未落盘 vs 已落盘但视觉失败的反馈真值；
- 退款/报销操作文案必须是当前 UI 真正能执行的动作。

## 已确认保持的产品边界

- 不新增转账、贷款、退款等完整会计交易类型。
- 账本估计仍是生活成本的一种估计方式。
- FREE 仍表示当前人生区间按当前口径被覆盖，不是永久退休证明。
- 公式结构不变；长账本只加强货币整数表示的精度。

微信开发者工具的字体抗锯齿、真实文件分享/选择、iOS/Android Canvas/WebAudio 仍属于官方运行时最终验收，不由本地 Node/Chromium 测试冒充。
