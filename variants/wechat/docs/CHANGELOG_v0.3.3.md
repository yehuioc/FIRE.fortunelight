# v0.3.3 Changelog · 内核统一

- 删除 v0.3.2 的上手版独立“当前余额公式”。
- 上手版 / 高级自主版重新统一为同一个原始账本计算内核。
- 新增“起始自由本金”：作为系统基准收入写入账本，让上手版无需等待也能立即产生自由天数。
- v0.3.2 quick 用户的旧 `initial_assets` 自动迁移为起始自由本金，避免结果突然归零。
- 快速版不再启用独立起始资产桶；高级版仍保留原项目的“额外起始资产”可选扩展。
- 重写交易 0 格变化反馈：区分取整边界、账本自动成本、固定起始资产、净储蓄非正与 overflow。
- “记录支出/收入”按钮统一为“更新自由时间”，不再承诺每一笔都必然点亮或熄灭整格。
- 首页和设置明确：两种模式只是输入复杂度不同，不是两套算法。
- 历史页把“起始自由本金”标记为系统基准，只能在设置中修改。
