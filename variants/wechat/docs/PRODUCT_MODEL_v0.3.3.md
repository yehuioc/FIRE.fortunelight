# 财富自由指南灯 v0.3.3 · 核心产品模型

## 核心问题

普通记账回答“我花了多少钱”。财富自由指南灯回答：

> 按照我采用的生活成本口径，我目前的净储蓄究竟买回了多少天不被下一份工资绑住的自由？

这里最重要的不是“财富数字更大”，而是把钱翻译成时间。生活成本是两者之间的汇率。

## 上手版

目标：第一次使用就理解、第一次设置就得到结果，但不牺牲公式一致性。

用户只需要提供：

1. 出生日期 / 目标年龄；
2. 日均生活成本；
3. 起始自由本金（可为 0）。

起始自由本金作为一笔系统基准收入进入账本。之后普通收入、普通支出继续进入同一个净储蓄公式。因此上手版没有等待期，也没有“假余额公式”。

## 高级自主版

目标：把输入控制权交回给理解模型的人。

可控制：

- 日均成本：手动 / 账本自动；
- 自动账本的统计天数覆盖；
- 起始自由本金；
- 可选的额外起始资产独立折算；
- 是否显示已经走过的人生；
- 目标年龄；
- 主题。

高级版不是更复杂的算法，只是更完整的参数面板。

## 交易反馈

反馈必须回答“为什么”。

- 点亮：告诉用户从多少天变成多少天，以及是净储蓄/日均成本哪个输入导致；
- 熄灭：同样说明变化来源；
- 0 格变化：不能只说“没有跨完整一天”，要区分手动成本、自动成本、固定起始资产、净储蓄非正、全部点亮等真实原因；
- 方格只显示整数天，但反馈可以展示精确值。

## 语言原则

- 不羞辱消费；
- 不把支出称作失败；
- 不承诺退休或投资收益；
- 不把目标年龄当寿命预测；
- 不要求用户“先坚持记录几天”才有资格看到结果；
- 不替高级用户偷偷做假设。
