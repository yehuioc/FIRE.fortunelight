# v0.5.0 — 核心语义对齐

本版继续冻结周边治理，不扩完整会计能力，不修改冻结数学公式。

## 核心变化

1. **自由事件**：普通记录语义从泛化“收入/支出”收紧为“新增财富/生活消耗”。账户互转、借款本金、重复信用卡还款不应进入自由模型；退款/报销优先修正原支出。
2. **生活成本是估计**：手动与账本只是对同一变量的两种估计方式。账本模式仍沿用冻结公式，但 UI 不再把它包装成绝对真值。
3. **支出不是惩罚**：方格熄灭继续真实发生，但反馈改为“把未来自由交换成今天的价值”，由用户判断这次交换值不值。
4. **FREE 语义收紧**：保留 `FREE / 财富自由` 仪式；删除 `FINANCIAL FREEDOM ACHIEVED`，改为 `CURRENT HORIZON FULLY COVERED`，明确其含义是当前人生区间按当前口径被覆盖，不是传统 FIRE 的永久退休证明。
5. **克制**：没有为了处理转账、贷款、退款等场景扩展完整会计交易类型。当前阶段优先做清楚“什么应该进入自由模型”。

## 不变项

- `computeStats` 数学计算段与 V0.4.4 完全一致。
- Camera、逐格点亮/熄灭、音效、FREE 主体仪式架构不变。
- 本地 Storage 结构不迁移，不新增账户体系。
