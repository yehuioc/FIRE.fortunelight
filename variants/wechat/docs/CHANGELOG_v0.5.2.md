# v0.5.2 — 真机显示与手动成本反馈修正

这是 v0.5.1 的小型真机反馈修正版，不改变产品语义和计算内核。

## 1. 纸张主题金额输入

真机反馈显示，“纸上自由”主题中出生日期、目标年龄已经是深色文字，但 `日均生活成本估计`、`起始自由本金` 等原生 `<input>` 数字仍可能渲染成白色。

V0.5.2 不再只依赖容器/后代 WXSS 的 `color`：

- 设置页所有金额输入增加专用 class；
- WXML 直接绑定当前主题的 `inputTextColor`；
- placeholder 同步绑定主题色；
- 首启流程的金额输入使用同样机制；
- 纸张主题保留 WXSS 深色规则作为第二层兜底。

纸张主题金额文字：`#40372e`。

## 2. 首页标题与“理念 / 设置”重叠

V0.5.1 的 flex 布局虽然在本地预览中过线，但真机仍出现品牌标题侵入右侧操作区。

V0.5.2 改为：

```text
[ minmax(0, 1fr) 品牌区 ] [ auto 操作区 ]
```

- 品牌区有独立 overflow 边界；
- 按钮区有独立 auto 列，标题不能绘制到其下方；
- 按钮去掉彼此依赖 margin 的宽度分配；
- “大字”只放大正文，不再继续放大顶栏品牌/导航按钮；
- ≤360px 进一步缩小顶栏字号、间距和按钮最小宽度。

## 3. ¥80/天真机测试回归

用户真机用上手版、日均生活成本 ¥80 实际测试 ¥50 / ¥100 / ¥200 / ¥300 / ¥800。

V0.5.2 增加正式测试保证：

- 每笔变化后的自由天数始终等于 `floor(当前净储蓄 ÷ 80)`；
- ¥50/¥100/¥200/¥300 单笔可能因交易前的小数天余量跨不同数量的整数格，这是正确行为；
- ±¥800 = ±10 个完整生活日，因此无论交易前余量如何，必须严格 ±10 格；
- feedback delta 必须与实际方格差一致。

核心公式没有因为这一测试发生任何修改。
