# V0.6.2 · 真机信息架构与阅读系统收口

日期：2026-09-20

本版不改财富自由公式，不改交易语义，也不增加新的会计能力。目标是修复 V0.6.1 真机截图暴露出的入口、排版、说明和字体缩放问题。

## 首页入口

- 品牌标题“财富自由指南灯”从操作按钮中独立出来，不再在窄屏被挤没。
- 顶部固定三入口：`理念 / 消费分析 / 设置`，“分析”不再使用含糊命名。
- `上周回顾` 从记录中心中拆出，成为首页独立入口；新一周有可回顾数据时点亮小灯，打开后熄灭。
- 周回顾入口明确标注会进入“消费分析”，避免把“记录中心”和“消费分析”混为一层。

## 记录中心

- 关闭“记录中心”后：首页整块真正不渲染，不再保留一个空壳。
- 成就仍可通过设置页的“查看记录与成就”进入，不再依赖记录中心必须开启。

## 使用说明

- `理念` 页面升级为“说明书”，包含 `使用指南 / 核心理念` 两个页签。
- 使用指南覆盖：快速记账、主分类 / 快捷标签 / 备注、消费性质、消费分析、周回顾、记录中心、成就、补账、首页布局、数据备份。
- 设置页新增“打开使用指南 / 查看核心理念 / 重新播放新手引导 / 查看记录与成就”。
- 记账区增加可关闭的极短就地提示；不把完整说明塞回首次引导。
- 消费性质明确为可选复盘标签：只用于用户自己的复盘，不改变自由天数公式。

## 首页布局

- 新增持久化 `home_module_order`。
- 可调整四个主体模块：自由概览、人生方格、记录中心、记一笔真实的账。
- 采用设置页“调整模式”的上移 / 下移，而不是首页长按拖拽，避免小程序滚动中的误触和复杂手势状态。
- 缺失、重复或未来未知的布局 ID 会自动清洗并补齐默认模块，不让旧备份或异常数据破坏首页。

## 字号系统

- 原 `紧凑 / 舒适 / 大字` 兼容迁移到 `90% / 100% / 110%`。
- 设置页开放 `85 / 90 / 95 / 100 / 105 / 110 / 115%` 七档。
- 首次引导仍只显示 90 / 100 / 110 三档，避免增加首启理解成本。
- 七个页面中现有明确字号都生成同倍率覆盖，标题、正文、辅助文字一起缩放，避免“大字更大、小字不动”的层级断裂。
- 字号范围限制在 85%–115%，不无限放大，避免挤坏窄屏布局。
- 系统黑体 / 宋体阅读的字体族继承统一到全页及 input / button。

## 细节排版

- “最近常用”的快捷标签由基线对齐改为居中对齐，`约会 / 正餐` 等组合不再上下错位。
- 窄屏顶栏单独做比例缩放，品牌和三个入口不再互相抢占。

## 自定义授权字体

用户已说明已取得目标字体的授权，但当前项目输入中仍没有该字体的具体文件、字体名称或可加载资源。因此 V0.6.2 先完成字体族入口和全局比例缩放基础，不伪造或嵌入未知字体文件。拿到字体资产后再做最终接入与真机字形验收。

## 验证边界

本版继续要求：自动化回归通过不等于微信真机验收。尤其需要再次检查纸上自由主题、320–430px 窄屏、85% / 115% 两端字号、首页四种模块顺序和授权字体最终接入后的换行变化。

## 自动化验收

发布前完整执行 `tests/run_release_preflight.sh`：旧版模型 / 备份恢复 / 生命周期 / 仪式 / 页面流回归、V0.6.0 分桶与分析、V0.6.1 习惯回路、V0.6.2 UI / 设置静态门禁均通过，最终输出 `RELEASE PREFLIGHT v0.6.2 PASSED`。

本轮 Node 基准中：50,000 笔核心长账本计算约 387 ms；10,000 笔月分桶写入约 38 ms、读取约 37 ms，最大单月 bucket 41,077 bytes。以上仅用于回归与量级检查，不能替代微信开发者工具和 iOS / Android 真机验收。
