# v0.3.0 微信小程序发布路线

## 1. AppID 与项目

- 在微信公众平台注册/进入小程序主体；
- 获取真实 AppID；
- 将 `project.config.json` 的 `appid` 从 `touristappid` 替换为真实 AppID；
- 用微信开发者工具直接导入项目根目录。

## 2. 基础信息与类目

当前产品核心是：用户主动记录个人收支，系统按历史日均生活成本做数学换算和可视化。

因此服务类目优先按微信后台当前实际可选项核对「工具 → 记账」。不要为了“财富自由”这个名称把产品描述成证券、基金、财富管理、投资顾问或收益服务；当前代码没有提供这些服务。

类目开放范围和主体资质可能变化，以提审当日微信公众平台为准。

## 3. 备案

面向中国大陆提供互联网信息服务的小程序，应按工信部 APP/小程序备案要求办理。权威通知：

https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html

## 4. 隐私配置

当前版本虽然不上传账本，但用户主动输入生日和账本信息，仍应按照平台表单如实说明处理目的、保存方式和删除入口。

参考 `PRIVACY_TEMPLATE.md`，不要错误填写成「完全不处理任何用户信息」。

## 5. 微信开发者工具验收

导入后先做：

- 编译零错误；
- 清缓存/清数据，检查首次引导；
- iPhone 模拟器；
- Android 模拟器；
- 修改生日/目标年龄；
- 记支出；
- 记收入；
- 删除历史记录；
- 清空本地数据；
- 检查 Canvas；
- 检查输入键盘和日期 Picker。

## 6. 真机体验版

上传开发版本，设为体验版，至少用一台 iPhone 和一台 Android 完整走一轮。

重点看：
- Canvas 是否稳定出现；
- 返回设置页后是否重绘；
- 首次引导是否绝对看不到主页 Canvas；
- 长备注是否截断正常；
- 小屏安全区域；
- 输入金额后键盘遮挡是否影响提交。

## 7. 提审文案建议

审核备注可写：

> 本小程序是一款个人生活记账与数学可视化工具。用户手动记录收入、支出后，应用根据从首笔有效记录到当前日期的历史日均生活成本，将净储蓄换算为可覆盖生活天数，并以人生方格展示。当前版本不提供证券、基金、理财产品、投资建议、收益承诺或资金交易服务；账本默认仅保存在用户当前设备的小程序本地存储，无需账号登录即可使用。

## 8. 发布

审核通过后，在微信公众平台版本管理中确认发布。发布前再执行一遍 `RELEASE_CHECKLIST.md`。
