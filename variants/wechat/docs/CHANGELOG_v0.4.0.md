# v0.4.0

- 冻结 v0.3.3 数学内核，本版本不改计算公式。
- 恢复最初电脑版的 Camera 追焦、缩放、逐格点亮、逐格熄灭主体体验。
- 点亮/熄灭的颜色、节奏和缩放档位重新向原 `frontend/grid.js` 对齐。
- 首页滚动区只展示静态方格图片；实时 Canvas 移到固定全屏交易仪式舞台。
- 增加大变化量自适应节奏和跳过入口。
- 恢复 FREE 财富自由达成仪式及五层波纹。
- 删除整页抖动与触觉震动路径。
- 最终方格快照改为 Promise 链路：正常情况下最终图准备好以后才退出仪式。
- 最终图失败时清除旧图并重新生成，避免数据与方格不一致。
- 新增 `utils/ritual_grid.js`、`tests/ritual_core.test.js` 和实时视觉预览。
- 音效等外围体验暂缓，先验证视觉主体。
