# 财富自由指南灯 v0.5.0 · 核心语义

> 本文件服从 `/mnt/data/user/wealth_freedom_beacon/CORE_ANCHOR_FIRST_PRINCIPLES_RESTRAINT_2026-08-22.md`。
> 本版不修改冻结数学公式，只统一“哲学 → 输入 → 数学 → 方格 → 反馈”的含义。

## 1. 第一性目标

让用户把抽象的钱稳定理解为可支配生命时间，并让每一次真实经济行为的时间影响被准确、直观、有心理重量地感知。

## 2. 自由事件

产品不是全现金流账本。普通记录只接受两种语义：

- **新增财富**：真正增加可支配自由资源；
- **生活消耗**：真正消耗生活资源。

不改变自由本质的现金流不应进入普通收支：账户互转、借款本金、重复信用卡还款等。退款/报销优先修正原支出。

此处刻意不扩展完整会计类型。当前“西瓜”是自由时间认知机制，不是会计覆盖率。

## 3. 生活成本

核心关系仍然是：

```text
自由时间 = 自由资源 ÷ 每日生活成本
```

V0.5.0 不改冻结公式。账本估计仍为：

```text
日均生活成本 ≈ 累计生活消耗 ÷ 观察跨度
```

但 UI 必须把它称作“估计”，不能暗示为绝对真值。手动估计与账本估计只是获得同一个变量的两种方式，不是两套模型。

## 4. 支出与熄灭

方格熄灭不是惩罚。它表达的是机会成本：

> 用户把一部分未来自由交换成今天的某种价值。

视觉仍然真实熄灭，因为未来自由确实减少；文字不再把消费道德化。

## 5. FREE

`FREE / 财富自由` 视觉保留，但精确定义为：

> 按当前生活成本估计、人生坐标与自由资源，现有资源已覆盖剩余人生方格。

它不是传统 FIRE 中基于安全提取率、投资收益率、通胀等条件证明的永久退休能力。

## 6. 克制边界

本版不为解决真实世界现金流语义而扩成完整会计软件。能通过“什么应该进入自由模型”的清晰定义解决的问题，不增加账户、借贷、信用卡等新模块。
