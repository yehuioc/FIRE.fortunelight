# V0.4.4 — 炒面式对抗测试修复

本版不改变冻结的财富自由计算公式，重点修复“用户行为合理但开发路径没想到”的对抗场景。

- 系统生成的“起始自由本金”仍计入净储蓄，但不再伪造账本自动模式的成本观察起点。
- 早于出生日期的历史交易不再进入模型；首页新增交易同时在日期选择和提交边界阻止。
- 设置 + 起始自由本金改为一个逻辑保存操作，跨 key 写入失败时回滚，避免半提交。
- 页面进入后台时直接终止实时仪式并落回最终数据，不再等待可能永远暂停的 RAF。
- 静态人生方格导出增加 RAF fallback 与 canvasToTempFilePath 超时兜底。
- 实时 RitualGrid 增加 watchdog，异常 RAF 不再永久悬挂 Promise。
- 删除历史记录后，如果统计起点/跨度改变，会明确显示“口径重算”，不把修正误导成新的财富增减。
- 新增 bar_regression / config_atomicity / fried_noodle_runtime 自动门禁。

仍需产品校准的不是代码错误，而是账本语义：内部转账、退款/报销、信用卡还款、借贷本金等真实世界事件是否以及如何进入自由模型。
