# v0.5.1 — 首启、可读性、备份与长期数据安全

v0.5.1 是 v0.5.0 的优化版，不改变“财富 → 生活成本 → 自由时间 → 人生方格”的产品锚点，也不引入第二套财富自由公式。

## 用户可见变化

- 6 步首启与轻量过渡动画；首屏先建立产品含义，再要求输入。
- 首次设置即可选择主题、系统黑体/宋体阅读、紧凑/舒适/大字。
- 出生日期、目标年龄、起始自由本金、额外起始资产、生活成本来源全部增加就地解释。
- 首页顶部品牌排版收口，原生导航栏不重复显示产品名。
- 本地数据完整 JSON 导出/导入；新环境首屏可直接恢复。
- 历史账本首批渲染 100 条，继续加载，不再一次生成成千上万 WXML 节点。
- 目标年龄自然到期时保留全部账本并明确提示更新人生坐标。
- 退款/报销说明改成当前真正可执行的动作：删除原支出，再按最终真实净消耗重新记录。

## 数据正确性与对抗修复

- 金额必须精确到分，不再静默把三位小数四舍五入成另一笔钱。
- 超长账本累计金额跨越 JS 安全整数后仍保留整数天边界精度，生产代码不依赖 BigInt。
- 备份、配置保存、旧内核迁移、清空等多 key 操作提供失败回滚。
- 写入/删除/导出走严格 Storage 读取；读取失败绝不等价于空账本。
- 脏 `system_kind/system_locked`、重复起始基准、重复内部 ID 在读取/备份边界规范化。
- 备份恢复不接受损坏的核心枚举设置；内部 kernel_version / next_id 由当前程序重建。
- 老版本 settings 导出时先升级到当前规范，保证“旧本地状态 → 新备份 → 新版本恢复”闭环。
- 设备时间回拨不会吞掉已经存在的合法交易；未来日期仍禁止新建。
- 保存高级配置后切到上手版并保存，不会永久删除高级参数。
- 首启/设置修改出生日期时，都会阻止把既有真实账本变成“出生前幽灵账”。
- 起始自由本金属于系统基准，不会因为之后修正出生日期而突然从净储蓄消失。
- 首启快速双击、提前点跳过、页面卸载后的迟到备份回调、设置保存后立刻返回等竞态已收口。
- 提交链明确区分“经济事件未落盘”和“已落盘但视觉失败”，反馈不再含糊。

## 验证

`tests/run_all.sh` 覆盖原有模型/Storage/仪式测试，以及 V0.5.1 的完整备份、生命周期、长账本、对抗与炒面矩阵。
