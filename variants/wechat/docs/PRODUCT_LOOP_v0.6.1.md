# V0.6.1 使用回路

目标回路：

`现实事件 → 3 秒左右完成记录 → 人生方格 / 自由天数即时反馈 → 记录痕迹持续积累 → 上周回顾形成观察理由 → 再次主动打开`

## 已实现

1. 整数自由日：沿用点灯 / 灭灯仪式。
2. 小数自由日：轻提示连续值变化，不修改整数格语义。
3. 记录痕迹：累计天数、连续性、覆盖率、12 周热力格。
4. 成就：正式里程碑 + 少量奇怪成就。
5. 降低摩擦：最近 90 天常用快捷标签前置。
6. 漏记恢复：温和补记，不把零记录自动判定成失败。
7. 周期理由：每周一开始，如果上一完整自然周存在真实记录，就点亮“上周回顾”入口；查看后熄灭。
8. FIRE 解释：记录中心可重新进入理念页。

## 刻意延期

### 每日动态卡片

仍然保留，但不在 V0.6.1 生成。原因不是否定它，而是它必须先满足两个条件：

- 能从真实账本中稳定找出“今天最值得看的一件事”；
- 不和现有人生方格、周报、消费分析争夺注意力。

候选洞察池可以包括：

- 本周某分类已超过上周整周；
- 本月某分类同比/环比异常；
- 最近 7 天“可省”消费为 0；
- 某常用标签在近期显著上升；
- 记录覆盖率发生明显变化。

但在没有可靠优先级排序前，不输出随机鸡汤或每天机械换一句话。
