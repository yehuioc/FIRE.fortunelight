# 财富自由指南灯 · 主体仪式定义 v0.4.1

本版本只定义产品主舞台，不扩张周边治理。数学内核继承 v0.3.3，不在这里改变。

## 主体闭环

用户提交交易后，先得到确定的 before / after 数据。只有 `lit_count` 跨过整数格，才进入仪式舞台。

1. Camera 找到自由边界。
2. 镜头按变化量选择 10 / 8.5 / 7 / 5 / 3.6 倍缩放。
3. 点亮：每格约 2000ms，从暗格经过暖金爆发与光晕，最终稳定为金色。
4. 熄灭：每格约 2600ms，从金色经过暖褐/灰烬回到暗格，节奏比获得自由更慢。
5. 自由天数只在对应单格动画完成后更新，数值必须服从视觉事实。
6. Camera 退回完整人生。
7. 新的最终静态方格快照生成成功以后，才关闭仪式舞台。
8. 如果第一次跨越最后一格，进入全视口 `FREE / 财 富 自 由` 达成仪式。

## 平时浏览

长页面中不保留可见实时 Canvas。人生方格由离屏 Canvas 生成静态 PNG，以普通 `image` 展示。今天坐标的呼吸使用普通 View/CSS 完成。因此页面滚动与实时仪式彻底分工。

## 声音

声音属于原版仪式的一部分，但不能成为交易成功的依赖条件。

- 点亮：短促高频合成钟鸣。
- 熄灭：较低、较慢的衰减音。
- 全部点亮：C 大调色彩的和弦 + 低音锚点。
- 大量格子变化时采样播放，避免创建过多音源。
- 不支持 `wx.createWebAudioContext` 时静默降级。

## 视觉不变量

- 放大时方格必须保持锐利，不能把低分辨率整图强行放大。
- 点亮只能沿暗 → 暖金 → 金色方向，不得出现黑块/错误色。
- 熄灭不是警报，不使用高饱和红色，也不震动整个页面。
- `delta = 0` 不演假仪式。
- 数据与最终静态方格不一致时，宁可加载，也不能展示旧图冒充新结果。
