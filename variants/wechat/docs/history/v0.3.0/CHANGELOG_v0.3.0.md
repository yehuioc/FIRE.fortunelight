# v0.3.0 变更记录

## 产品结构

- 首次引导前三页保留核心理念、正确心态、反馈机制。
- 第四页重构为“上手版 / 高级自主版”。
- 删除“前 7 天观察期”作为默认产品要求。
- 首页不再展示记账跨度/观察期，改为展示“使用模式 + 成本口径”。

## 上手版

- 日均生活成本由用户直接设定。
- 起步基准可支配资金由用户设定。
- 完成首次配置即可即时点亮人生方格。
- 后续交易净变化直接作用于可支配财富。

## 高级自主版

- 日均成本可选手动或账本自动。
- 自动模式支持统计天数覆盖。
- 支持开关起步资产、显示过去人生。
- 保留目标年龄控制。

## 主题

- 保留 `深夜金`。
- 新增 `纸上自由`。
- Canvas、页面背景、卡片、表单、按钮和导航栏共同切换。

## UI 修复

- 主要按钮全部改为 Flex 几何居中。
- 输入字段增加确定高度/line-height，减少字段文字垂直偏移。
- 第四页使用内部 `scroll-view`，底部按钮与分页点固定在安全区域，不与高级设置争夺空间。

## 模型修复

旧实现中 `initial_assets / cost + max(0, net_savings / cost)` 会导致“只有支出时并不会减少起始资产对应的自由天数”。v0.3.0 改为：

`effective_wealth = max(0, baseline_assets + income - expense)`

`freedom_days = floor(effective_wealth / daily_cost)`

因此支出和收入都会如实改变当前自由天数。

## 数据兼容

v0.3.0 使用稳定 Storage key，并对 `wfb.v020.*` 做透明读取迁移；旧版 `avg_daily_expense_override` 也会映射到新成本模式。
