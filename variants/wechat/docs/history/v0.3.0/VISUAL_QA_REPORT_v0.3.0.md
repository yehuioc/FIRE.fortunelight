# v0.3.1 视觉与交互预检报告

日期：2026-08-21

## 方法

在代码测试通过后，使用 Chromium + Playwright 对 v0.3.1 视觉等价夹具进行多视口截图，并由视觉模型逐张检查。该夹具用于提前发现布局错误，不冒充微信开发者工具运行时。

## 已检查画面

390×844：
- 深夜金首页；
- 纸上自由首页；
- 第四页上手版；
- 第四页高级自主版；
- 深夜金设置；
- 高级设置；
- 纸上自由设置。

360×800：
- 两套主题首页。

320×568：
- 第四页上手版；
- 第四页高级自主版。

## 检查结果

- 所有视口 `scrollWidth == clientWidth`，无横向溢出。
- 上手版第四页完整展示关键字段与固定底部操作区。
- 高级版第四页在小屏采用可滚动正文区，底部分页点/按钮保持独立，不遮挡正文。
- 首页支出按钮文字在视觉夹具中为 Flex 几何居中；生产 WXSS 同样使用 `display:flex; align-items:center; justify-content:center`。
- 输入字段生产 WXSS 显式设定高度与 line-height，针对微信 input 的垂直基线做保守处理。
- `纸上自由` 不只是换背景色：Canvas、卡片、分段选择、表单、按钮、强调色均有独立配色。
- 深夜金仍维持原来的黑金识别度。

## 视觉判断

上手版的“两个数字立即点亮”信息层级清晰；高级版的信息密度明显更高，但通过滚动区与分组维持可读性，符合“懂理念的人主动选择高级”的定位。

## 不能替代的最终检查

仍需在微信开发者工具和 iOS/Android 真机检查：
- `scroll-view` 真实滚动手感；
- `input` 字段系统字体基线；
- `switch` 原生组件在两套主题下的观感；
- Canvas DPR；
- 导航栏动态换色。
