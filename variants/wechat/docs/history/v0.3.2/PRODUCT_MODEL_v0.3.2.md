# 财富自由指南灯 v0.3.2 · 产品与交互模型

## 两种使用模式

### 上手版 · 余额口径

目标：第一次配置后立即点亮，并让每笔收支都产生直觉反馈。

用户只需要给出：
- 日均生活成本；
- 当前可支配资金。

之后：收入增加当前资金，支出减少当前资金，再用“当前资金 ÷ 日均成本”得到自由天数。

### 高级自主版 · 原始账本模型

目标：把最初设计的 FIRE-inspired 账本模型完整交给用户。

用户可决定：
- 日均生活成本手动设定 / 账本自动；
- 统计天数；
- 是否纳入记账起始资产；
- 是否显示过去人生；
- 主题。

高级版的数学关系以 `MATH_INVARIANTS.md` 为准，不因 UI 重构而变化。

## 人生方格渲染

v0.3.2 不再让可见 Canvas 长期处于滚动页面中：

`Canvas 2D 绘制 → wx.canvasToTempFilePath → 普通 image 展示`

Canvas 保持透明，只承担绘制/导出。普通 image 跟随页面布局滚动，解决高速滑动时 Canvas 内容短暂拖影、延迟归位的问题。

交易导致方格变化时：
1. 重新计算；
2. 导出一张“变化区高亮”的快照；
3. 显示约 520ms；
4. 再导出稳定最终快照。

不再使用整机震动，也不做整页抖动。

## 交易反馈

反馈必须回答三件事：
- 点亮 / 熄灭多少格；
- 当前自由天数从多少变多少；
- 为什么。

上手版示例：
> 熄灭 11 天自由 · -11 格
> 本次支出 ¥1,100，当前可支配资金约 ¥8,850，自由时间从 99 天变为 88 天。

若没有跨过完整一天，则明确告诉用户距离下一格还差多少金额，而不是只说“口径已同步”。
