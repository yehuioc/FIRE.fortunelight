# v0.3.2 Changelog

## 核心修复

- 修复人生方格 Canvas 高速滚动时内容短暂拖影/延迟归位：可见方格改为 Canvas 导出的普通 image。
- 删除 `wx.vibrateShort` 交易反馈，不再让整台设备产生廉价“抖动感”。
- 修复上手版“记账后方格完全不动”的核心问题：上手版明确采用当前余额口径，收支直接改变当前可支配资金并重新点亮/熄灭。
- 用户回归案例已加入自动测试：¥10,000、¥100/天 → 100 天；支出 ¥50 → 99 天；再支出 ¥1,100 → 88 天。
- 高级自主版继续保留最初设计的原始账本公式，不改成 effective-wealth 合并模型。

## 交互

- 首页增加“当前模式”入口，明确显示上手版 / 高级自主版及当前口径，可直接进入设置调整。
- 上手版交易区明确提示“每笔收支直接改变当前可支配资金与自由天数”。
- 支出按钮在上手版改为“记录支出 · 熄灭自由时间”。
- 反馈卡新增 `+N 格 / -N 格 / 0 格`，并给出具体资金和自由天数变化。
- 0 格变化时给出距下一格的具体金额，不再使用“虽然没跨过一天但已同步”的空泛解释。

## 渲染 / UI

- Canvas 仅作为透明绘制表面，不再直接展示。
- 收支变化使用高亮快照 → 稳定快照，不做持续可见 Canvas 动画。
- 输入字段补充显式 line-height，继续收紧微信基础组件的垂直基线偏移。

## 测试

新增 `grid_render.test.js`，验证：
- Canvas 2D 正常绘制；
- `wx.canvasToTempFilePath` 使用实际 canvas node；
- 导出后 `gridImagePath` 正确更新。
