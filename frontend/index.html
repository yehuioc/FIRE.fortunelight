使用指南 / 核心理念

钱不是终点，选择才是。

指南灯把你已经拥有的自由资源，按你采用的生活成本估计，翻译成能自主支配的天数。它帮助看见选择的代价，不要求每一次消费都更少。

先建立一个可用的估计

上手模式只需要出生日期、目标年龄、日均生活成本和起始自由本金。目标年龄是你选择的人生坐标，不是寿命预测。本金会成为一笔系统基准收入，后续生活消耗从账本净储蓄中扣减。

这里只记录“自由事件”

新增财富是可用于自己生活的净新增资源；生活消耗是实际发生的个人成本。账户互转、借款本金、投资资产内部搬动，以及已经记过消费的信用卡还款，都不再重复计为收支。退款或报销：编辑原支出为最终净消耗；全额退回时删除原记录。

一格是一天，小数也有意义

方格只显示完整自由日。保存真实交易后，小提示会显示估算天数的变化；跨越完整一天才播放点亮或熄灭仪式。消费是把未来自由交换成今天的价值，值不值由你决定。首次建立成本、修改设置或修正旧账时，系统直接重算，不伪装成单笔财富的奖励。

分类、标签与性质

一笔生活消耗只有一个主分类，金额不会重复统计。快捷标签带入分类、默认备注和消费性质，但不会替你填写金额。“必要 / 可调 / 可省”是可选的自我复盘标签，不改变自由天数。缺乏事实的历史记录保留为“未分类 / 未设定”。

看周期，也看同期

消费分析支持周、月、年和历史周期。当前周期只与上一周期的对应进度比较；已结束周期按完整周期比较。按主分类、快捷标签查看趋势，CSV 适合阅读与表格分析。上周回顾直接进入上一完整自然周的消费分析。

记录中心与温和提醒

累计记录天数、当前连续、历史最长连续、覆盖率和十二周活动格，都来自真实账本；起始本金不算签到。今天还没结束时保留截至昨天的连续链。漏记提示只帮你想起真实发生的事，不生成记录。记录中心、成就、常用入口和回顾灯都可以分别关闭。

高级模式：把输入控制权交给你

生活成本可改用“累计生活消耗 ÷ 首笔真实记录至今天的跨度”，也可覆盖统计天数。账本估计会受到漏记、补账和时间推移影响，它不是绝对真值。额外起始资产是独立折算的桶，负净储蓄不会直接扣掉它；不要与起始自由本金重复填写同一笔钱。切换上手模式会停用这些高级参数，切回时可恢复。

FREE 表示什么

按当前生活成本估计与人生坐标，现有自由资源已覆盖剩余人生区间。它不是永久退休证明，不预测通胀、投资收益或未来支出；修改假设会改变结果。

本地使用与备份

账本保存在此电脑的 SQLite 文件中，无账号、无云同步。设置中的 JSON 导出用于完整恢复；恢复前会预览并自动备份当前数据库。支持导入微信小程序 v1 / v2 JSON 备份，源码压缩包不含你的手机账本。请把备份另存到你信任的位置，本地存储本身不等于灾备。
